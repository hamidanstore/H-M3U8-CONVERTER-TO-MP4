Bantuan Penggunaan

Aplikasi ini membaca struktur file HLS (M3U8) yang terunduh di penyimpanan Anda.

  1. Siapkan folder yang berisi file .m3u8 dan folder segmentasinya (biasanya berakhiran _contents).
  2. Buka aplikasi, klik Scan Folder, dan izinkan akses baca folder tersebut.
  3. Pilih video yang ingin di-gabung.
  4. Klik Gabungkan ke MP4.
  5. Tunggu proses selesai, file MP4 akan otomatis terunduh ke perangkat Anda.
